Cineflow

A desktop companion for a cinema chain’s product team: tasks, an AI copilot and visual QA, on Mac and Windows.

23

The setting

Developers lived in five windows.

The team behind a cinema chain’s apps tracked tasks in one place, wrote code in another, and checked screens by eye before every release.

Cineflow brings the task, the code helper and the test results onto one desktop, on whichever operating system the developer uses.

Role
Desktop developer
When
October 2026
Platforms
macOS, Windows
Status
Internal tool
The quest

From ticket to tested, on one desk.

A four-column board syncs with the team’s tickets. Any task can be started with the Copilot, which drives local AI coding agents and always shows the diff before applying anything.

A QA suite runs browser tests and shows a visual diff against the approved baseline, so a moved button is caught before the audience sees it.

The craft

Mac is the reference. Windows matches.

Two native apps share one API contract and one QA runner. macOS defines the behaviour, and Windows follows it screen for screen.

  • SwiftUI
  • WinUI 3
  • C#
  • Swift
  • Playwright
  • OIDC + PKCE
  • AI agents
The ending

Cineflow is an internal tool, so you see an illustration rather than the real screens.

Building two native apps that feel identical taught Glen to write the spec first. Parity is a feature, and it needs a document.
