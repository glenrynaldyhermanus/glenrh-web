Devant

One workspace for a whole team: projects, docs, chat, whiteboards and an AI helper that knows where everything is.

21

The setting

Seven tabs to do one thing.

Teams were juggling a board, a doc tool, a chat app and a whiteboard, with the context scattered across all of them.

Devant pulls those into one workspace, signed in once, with the same people and the same projects everywhere.

Role
Web developer
When
From February 2026
Platform
Web app
Status
Ongoing
The quest

Everything a team touches.

Kanban boards for the work, a document editor for the thinking, a whiteboard for the messy part and chat for everything in between.

An AI assistant sits on top, so asking “where did we decide that?” actually gets an answer.

The craft

Enterprise plumbing, friendly face.

Single sign-on comes from Keycloak, data lives in PostgreSQL through Prisma, and real-time chat runs on its own Firebase functions. Releases ship through CI as a container.
