MAVIS

A studio of AI agents that live on Glen’s Mac, Android phone and iPhone, and can hand work to each other.

15

The setting

One assistant wasn’t enough.

Glen builds across many platforms at once. A single chat window that forgets everything between sessions was slowing him down.

What he wanted was a small team: specialists that remember how he likes things done, talk to each other, and can start a build on the Mac from a phone on the couch.

Role
Solo: architecture to apps
When
September 2026
Platforms
macOS, Android, iOS
Status
Private
The quest

A team with a shared memory.

MAVIS has an agent builder, one-on-one chats that stream, and war rooms where several agents work on the same project together.

A memory studio collects Glen’s design DNA, the rules he keeps repeating, so the agents stop asking. And a device mesh lets the phone ask the Mac to build.

The craft

One brain, three native faces.

The core is a pure Go daemon. Every client is fully native and keeps one-to-one feature parity, and MAVIS speaks MCP both ways: it uses MCP tools, and it can be one.

  • Go
  • WebSockets
  • Swift 6
  • SwiftUI
  • Kotlin
  • Jetpack Compose
  • MCP
The ending

MAVIS runs on Glen’s own devices. Five agents (Byte, Pixel, Buzz, North and Scan) share the work, and the phone can kick off a Mac build.

It’s private, but the idea of small, focused helpers runs through this whole book.
