MAVIS

A studio of AI agents that ship product: a small team of specialists on Glen’s Mac, Android phone and iPhone.

25

The setting

One assistant wasn’t enough.

Everything else in this chapter was shipped by a very small team. A single chat window that forgets everything between sessions was slowing that team down.

What I wanted was a product team of agents: specialists that remember how I like things done, talk to each other, and can start a build on the Mac from a phone on the couch.

Role
Solo: architecture to apps
When
September 2026
Platforms
macOS, Android, iOS
Status
In daily use, private
The quest

A team with a shared memory.

MAVIS has an agent builder, one-on-one chats that stream, and war rooms where several agents work on the same project together. Each agent has a job: code, design, growth, product, QA.

A memory studio collects my design DNA, the rules I keep repeating, so the agents stop asking. And a device mesh lets the phone ask the Mac to build.

The craft

One brain, three native faces.

The core is a pure Go daemon. Every client is fully native and keeps one-to-one feature parity, and MAVIS speaks MCP both ways: it uses MCP tools, and it can be one.

  • Go
  • WebSockets
  • Swift 6
  • SwiftUI
  • Kotlin
  • Jetpack Compose
  • MCP
The ending

MAVIS runs on my own devices every day. Byte, Pixel, Buzz, North and Scan share the work, and the phone can kick off a Mac build.

It’s private, but it is how the rest of this book got built so fast.
